# OmniTools

A production-ready Next.js 15 App Router foundation for a premium SEO-first utility suite.

## Stack
- Next.js 15
- TypeScript
- Tailwind CSS
- Supabase
- PWA support

## Start
```bash
npm install
npm run dev
```

## Notes
- The tool registry is the single source of truth.
- Many tools share reusable processors and UI shells.
- PDF/image/text/dev tools have the strongest working examples in this foundation.
- Add new tools by extending `src/lib/tools/catalog-data.ts`.
